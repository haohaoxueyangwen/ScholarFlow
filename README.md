# ScholarFlow

ScholarFlow is a research-assistant project built around the Pi agent runtime.
Pi handles model interaction and sessions; ScholarFlow provides research tools,
evidence-linked notes, project-scoped knowledge, and reviewable write operations.

> **Repository status:** the public repository has been created, but the source
> export is still being reviewed and is not published yet. This repository is not
> currently an installable release.

The intended research workflow is: select a project and a PDF, discuss selected
pages with Pi, review a proposed note, and search approved notes with links back
to their sources. Model and knowledge services require separate configuration;
neither a local model nor an external API is included in this repository.

Before source publication, local research data, personal configuration,
credentials, machine-specific paths, and existing Git history are being excluded
or reviewed. The project-level license has not yet been selected; public
visibility alone does not grant an open-source license. Third-party components,
if included, will retain their applicable license and attribution files.
